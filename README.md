# OANH SƠN HRM – Quản lý hồ sơ nhân sự

Bộ ứng dụng HTML chạy trên trình duyệt, có thể triển khai bằng GitHub Pages.

## Tệp chính
- `index.html`: ứng dụng
- `icon-oanh-son-hrm.png`: biểu tượng dùng cho iPhone và trình duyệt
- `site.webmanifest`: cấu hình cài ứng dụng dạng web app

## Cài trên iPhone
Mở website bằng Safari → Chia sẻ → Thêm vào Màn hình chính.

## Lưu trữ dữ liệu
Ứng dụng dùng IndexedDB trên trình duyệt hiện tại. Dữ liệu trên máy tính và iPhone không tự đồng bộ với nhau; hãy dùng chức năng sao lưu/khôi phục để chuyển dữ liệu.

## Lưu ý bảo mật quan trọng
Không công khai mã nguồn có chứa dữ liệu nhân sự thật. Hãy kiểm tra và loại bỏ dữ liệu cá nhân khỏi mã nguồn trước khi đưa lên một repository Public. Dùng phương án lưu trữ riêng tư và phân quyền phù hợp với hồ sơ nhân viên.
